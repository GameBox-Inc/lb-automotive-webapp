STEP 6: CONFIGURE ANTHROPIC API (REQUIRED)
================================================================================

# Since Ollama is removed, backend MUST use Anthropic Claude API
# Ensure ANTHROPIC_API_KEY is set:

kubectl create secret generic anthropic-secrets -n lb-automotive \
  --from-literal=ANTHROPIC_API_KEY="YOUR_ANTHROPIC_KEY_HERE" \
  --from-literal=ANTHROPIC_MODEL="claude-3-5-sonnet-20241022" \
  --dry-run=client -o yaml | kubectl apply -f -

# Update app secrets to use Anthropic:
kubectl create secret generic app-secrets -n lb-automotive \
  --from-literal=LLM_PROVIDER=anthropic \
  --from-literal=SECRET_KEY="$(kubectl get secret app-secrets -n lb-automotive -o jsonpath='{.data.SECRET_KEY}' | base64 -d)" \
  --from-literal=ALLOWED_ORIGINS="$(kubectl get secret app-secrets -n lb-automotive -o jsonpath='{.data.ALLOWED_ORIGINS}' | base64 -d)" \
  --from-literal=DATABASE_URL="sqlite:////app/data/lb_automotive.db" \
  --from-literal=REDIS_URL="redis://redis:6379/0" \
  --from-literal=CSP_POLICY="strict" \
  --dry-run=client -o yaml | kubectl apply -f -

# Restart backend to pick up new config
kubectl rollout restart deployment backend -n lb-automotive

STEP 8: OPTIONAL BUT RECOMMENDED - ADD SWAP SPACE

================================================================================
TROUBLESHOOTING
================================================================================

If frontend still won't start:
1. kubectl describe pod <frontend-pod> -n lb-automotive
2. kubectl logs <frontend-pod> -n lb-automotive --previous
3. kubectl delete pod <frontend-pod> -n lb-automotive

If memory is still tight:
1. Check for rogue processes: ps aux --sort=-%mem | head -20
2. Check Redis: kubectl exec -n lb-automotive deployment/redis -- redis-cli info memory
3. Add swap space (see Step 8)

If disk is full:
1. sudo /etc/cron.daily/disk-cleanup
2. sudo docker system prune -af --volumes
3. sudo journalctl --vacuum-size=100M
